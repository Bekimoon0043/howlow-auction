# User Manual – HowLow

## Registration & Login
- Use your Ethiopian mobile number only (`+2519…` or `+2517…`) + password.
- No email required.

## Wallet
- Balance is in **ETB**.
- To add money: pay admin via bank transfer / Telebirr, then message them on Telegram with your phone + amount.
- Optionally submit a Deposit Request in the app as a reference.

## Bid Credits
- Every bid costs credits (shown on each auction).
- Buy packages by contacting admin on Telegram; admin credits your account.

## How to Bid
1. Open an active auction.
2. Enter a number (up to 2 decimal places).
3. You cannot reuse the same number on the same auction.
4. Your bid is secret – nobody else can see it while the auction is running.

## Winning
- When the timer ends the system finds the **lowest unique** bid.
- If you win you will receive an in-app notification and can complete shipping details under My Orders.

## Language & Theme
- Default language is Amharic. Switch to English in Profile.
- Dark / Light mode available in Profile.
